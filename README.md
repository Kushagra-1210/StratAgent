# StratAgent

An autonomous AI system powered by **CrewAI** and **Groq (Llama-3)** designed to act as a world-class strategy consulting team. The system accepts a company name and a specific business problem, autonomously fetches live financial and news data, and synthesizes it into a highly structured, MBB-style strategy brief.

## Architecture

The system utilizes a multi-agent orchestration architecture:
1. **Senior Research Analyst Agent**: Equipped with custom Python tools (`fetch_news`, `fetch_financials`), it searches Livemint, Google News, and Screener.in to compile a robust repository of quantitative data and real-time market sentiment.
2. **Management Consultant Agent**: Operating without internet access, this agent synthesizes the raw data. It is strictly prompted to find the "Strategic Tension," compare raw numbers vs. management narrative, evaluate risks, and formulate actionable recommendations.

## Prerequisites

* Python 3.10+
* Groq API Key

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file in the root directory and add your API key:
   ```env
   GROQ_API_KEY=your_api_key_here
   ```

## Usage

Run the agent from the command line by passing the `--company` and `--problem` arguments:

```bash
python main.py --company "Zomato" --problem "Impact of fuel price hike on profitability"
```
The final generated StratAgent brief will be automatically saved as a markdown file in the `output/` directory.
